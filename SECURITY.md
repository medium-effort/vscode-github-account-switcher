# Security Policy

## Supported Versions

We actively provide security updates and patches for the following versions:

| Version | Supported          |
| :---    | :---               |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability or potential credential handling issue within this extension, please follow these steps:

1. **Do not open a public issue.**
2. Report the vulnerability privately by emailing the maintainers or creating a private security advisory on GitHub under the **Security** tab.
3. Include as much detail as possible:
   - Clear steps to reproduce the issue.
   - The version of the extension, OS, and VS Code.
   - Expected vs actual behavior.
   - Any relevant logs or minimal code reproduction.

We will acknowledge receipt within 48 hours and work with you to triage and release a patch promptly.
